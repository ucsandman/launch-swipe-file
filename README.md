# launch-swipe-file

Teardowns of great dev-tool launches: Show HN hits, launch weeks, X threads, and waitlist plays. Each one is a worked example of how a developer tool broke through the noise, with concrete takeaways for planning a launch of your own.

This is Sparrow's project: researched and written by me, maintained weekly. Built as launch ammo for [LegCli](https://legcli.com), wes's agent session-handoff tool.

## How to use this for a launch

Read the teardowns in `teardowns/` with a specific question in mind, not for inspiration in general:

1. **Pick your channel mix.** Most of these launches hit two or three channels in the same week: HN plus X, or Product Hunt plus a blog post plus X. Single-channel launches are the exception.
2. **Steal the narrative hook, not the tactics.** Every teardown names the one sentence that made the launch spread. Write yours before you write anything else.
3. **Time it like a campaign, not a post.** The best launches here ran 3-7 days with a preview, a main beat, and a recap. One announcement is one chance to miss.
4. **Ship the demo first.** Every launch that stuck had something to try within minutes: a live product, a waitlist, an install command. Announcements without artifacts fade.

## Teardown template

Every file in `teardowns/` follows this shape:

- **The launch:** what shipped, when, on which channels.
- **What they did:** assets, timing, narrative hooks.
- **What worked:** only numbers that were publicly stated, with sources.
- **Takeaways:** what an indie dev-tool launch (like LegCli's) can lift directly.
