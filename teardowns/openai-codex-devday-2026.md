# OpenAI DevDay 2026: Codex goes to the cloud

## The launch
OpenAI held DevDay 2026 in San Francisco on September 29, 2026. OpenAI's recap lists 25 announcements across ChatGPT, Codex, the API, and a new always-on agent called dots. The Codex-specific launches: a refreshed Codex CLI (voice input, multi-task tracking view), Code Review (read and question GitHub pull requests from the ChatGPT desktop app), reusable Codex cloud environments (start tasks from a computer or phone, keep running while your machine is asleep), and Codex Security Cloud.
Sources: https://nerdschalk.com/everything-openai-launched-at-devday-2026/ and https://www.neoteo.com/en/openai-expands-codex-and-apis-at-devday-2026

## What they did
- Put the refreshed Codex CLI and Code Review on ALL plans, free included, while gating Codex cloud environments and Security Cloud behind paid tiers. Free users become the demo engine.
- Sold cloud environments as "reusable environments with shared settings and permissions," turning remote agents from a demo into team infrastructure.
- Tied the Codex beats to a monster metric: token traffic on the Responses API is up 100x year over year, stated by OpenAI's Thibault Sottiaux on X.
- Used one keynote as the single launch moment, then let press and ecosystem blogs slice the 25 announcements by plan and feature, multiplying coverage across the week.

## What worked
- 25 announcements in one keynote, 7 reaching Free and Go users, with refreshed Codex CLI and Code Review live on every plan at announcement.
  Source: https://nerdschalk.com/everything-openai-launched-at-devday-2026/
- Token traffic on the Responses API up 100x year over year, stated by Thibault Sottiaux on X.
  Source: https://nerdschalk.com/everything-openai-launched-at-devday-2026/
- Pro 500 tier at $500/month with Ultrafast, generating GPT-6 Astra tokens up to 8x faster in Codex, per OpenAI's recap.

## Takeaways for LegCli
- Gate the power, free the tool. Codex put the CLI and Code Review on every plan and gated cloud environments behind paid tiers: free users carry the launch while paid tiers carry the revenue.
- Name the one workflow sentence. "Work keeps going while your computer is asleep" sells cloud agents to every developer who runs a CLI locally. Your equivalent sentence is the whole launch.
- Numbers need a human owner. A 100x traffic stat quoted from a named OpenAI engineer on X travels further than the same number in a press release.
- One launch day, many slices. A single announcement that press can re-cut by plan, by feature, by price buys a week of coverage with no second press release.
