# universal-modder: "Every game is moddable now"

## The launch
On September 30, 2026, Rehan Sheikh announced universal-modder in an X post: "Every game is moddable now! I packaged everything Claude learned modding Terraria and Age of Empires into universal-modder: skills + tools that let Claude Code mod almost any game you own. Engine recon, decompiling, @fal sprites/3D/audio, testing in the real game, even the..." The project also lists Codex, Cursor, Gemini CLI, GitHub Copilot, and other compatible coding agents. Follow-up posts demonstrated a Minecraft x GTA V crossover mashup built with the workflow.
Source: https://bitcoinversus.tech/2026/10/01/gaming-universal-modder-turns-ai-coding-agents-into-pc-game-modders/

## What they did
- Opened with an impossible sentence: "Every game is moddable now!" A universal claim on an absurdly hard domain earns the click.
- Packaged the lessons from two completed projects (Terraria and Age of Empires II) into reusable skills and tools. The launch was the third iteration, not the first experiment.
- Shipped the full loop, not a code generator: engine identification, modding-route selection, asset generation, automated screenshots, game-window testing, packaging, and a shared knowledge base.
- Led with video proof: a Minecraft x GTA V mashup running in the real game, an outcome anyone can judge in seconds.
- Timed it into a viral wave: the X post landed as AI-assisted game modding mashups were trending, and a breakdown article amplified the story the next day.

## What worked
- Earned press coverage within 24 hours: bitcoinversus.tech covered the launch on October 1, one day after the X post.

## Takeaways for LegCli
- Ship the demo, then the toolkit. universal-modder launched as the packaged lessons of two finished mods; LegCli launches as the packaged lessons of hundreds of session handoffs.
- Impossible-sentence marketing. "Every game is moddable now" does in five words what a feature list cannot. Your equivalent sentence is the whole launch.
- Distribute as skills, not a product. Skills plus tools inside the agent the user already runs means no install friction and no new app to adopt.
- Close the loop visibly. The toolkit tests in the running game; show LegCli resuming a session, not describing handoffs.
